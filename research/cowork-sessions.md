## Lessons for our design

1. **Separate "where execution happens" from "where context lives".** Every failure above that hurt was an execution-location surprise (92144, Devin VM, Remote Control on origin host). Show the executing host in every surface, and make the surface name it.
2. **Do not rely on paths being identical.** Session stores keyed by absolute cwd broke on username change (45447) and on project-key mismatch (92734). Store project identity as a repo ID plus path relative to `$HOME`, and rewrite on import, with a dry-run.
3. **Keep the process alive outside the client connection.** Remote-SSH client reconnect killing the daemon's process groups (73304) and Cursor's window-bound throttling both show client lifecycle leaking into agent lifecycle. Run agents under tmux/systemd on the always-on box; treat the phone/laptop as a viewer.
4. **Commit or sync before handoff, and verify the handoff.** Devin carries uncommitted diffs; Claude teleport dropped turns and history. Acceptance test for any handoff: same turn count, last user message, and `git status` on both ends, checked by a script, not by eye.
5. **Persist workspace by mount or git, never by container.** OpenHands and Codex-style containers lose state unless mounted or pushed; this is also the cheapest backup story for a 4090 box.
6. **Expect indexers and resume pickers to lag.** Resume lists skipped valid sessions (28039) and went empty for weeks (97894). Our tooling should list sessions from the filesystem, not from an index file.
7. **Budget for metered cloud storage and idle time.** Codespaces bills stopped environments for storage; Codex caches 12 h. Keep the always-on box as the default home and use cloud VMs only for burst or isolation.
8. **Cross-check before trusting.** Most Claude Code session facts above come from GitHub issues (reporter-level), not maintainer docs; version numbers vary (2.1.49 to 2.1.293). Re-test on our installed version before designing around any of them.
