## top recommendations

1. 先验证 `whenToUse` 这个非标准 frontmatter key：在 Claude Code 装 plugin 后看 16 个 skill 是否都能被发现；若有风险，并入 `description`，`check.mjs` 按官方白名单校验（P0）。
2. 给 mstack 加可执行的触发测试（参考 anthropics/skills 的 skill-creator 与 superpowers 的 tests/explicit-skill-requests）：每个 skill 5 条应触发、5 条不应触发的提示词，先覆盖 m-start、m-review、m-verify。
3. m-guard 从纯文字提醒升级为可选的 PreToolUse 钩子片段（参考 gstack careful/freeze），硬拦 `rm -rf /`、force-push 默认分支和冻结目录之外的 Edit/Write；钩子默认不装，由用户决定。
4. 把"只读 agent"落到工具权限上：m-review、m-verify 在 Claude Code 下指定只读的 subagent 类型（参考 ECC agents 的 `tools:` 字段），而不是只靠"写的人不审"。
5. 在 `check.mjs` 里补字节上限与目录白名单（参考 superpowers tests/skill-size、skill-layout），并在 `E:\mstack\AGENTS.md` 放一个 20 行的仓库约定文件（参考 OpenHands）。
